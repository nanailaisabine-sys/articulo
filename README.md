# La seda de araña: artículo de revista

Artículo con diseño de revista digital sobre la seda de araña, enfocado en tipografía y texto que se adapta a cualquier pantalla. Es el proyecto 9 de mi ruta de 100 proyectos de desarrollo web.

## Tecnologías
- HTML5 semántico
- CSS
- Google Fonts: Playfair Display e Inter

## Lo que aprendí
- Cargar fuentes de Google Fonts de forma eficiente con `preconnect` y `display=swap`
- Combinar una tipografía serif para títulos y una sans-serif para texto
- Las unidades de CSS: `px`, `rem`, `em`, `%`, `vw` y `ch`, y cuándo usar cada una
- Limitar el ancho de las líneas a unos 65 caracteres con `ch` para leer cómodamente
- Tipografía fluida con `clamp()`, sin consultas de medios
- Estilizar contenido sin clases con `:where()` para mantener baja la especificidad
- Letra capitular con `::first-letter` y `float`
- Títulos y párrafos equilibrados con `text-wrap: balance` y `text-wrap: pretty`
- Personalizar el color de selección con `::selection`
